# Healthcare Recommendation MLOps Lab

Production-style healthcare recommendation MLOps platform.

## Learning Objectives

- Kafka event streaming
- Kafka Connect
- Spark Structured Streaming
- Databricks Delta Lake
- Bronze / Silver / Gold architecture
- Feature engineering
- Offline and online feature serving
- Multiclass classification
- Logistic Regression, XGBoost, and KNN
- MLflow experiment tracking and model registry
- Redis online feature serving
- FastAPI low-latency inference
- Docker and Kubernetes
- Terraform infrastructure as code
- Jenkins CI/CD
- Git feature branches and pull requests
- Model and data observability
- Delayed-label evaluation
- Precision@K, Recall@K, NDCG@K
- A/B testing
- Python cProfile performance profiling
- Spark performance analysis
- Text-to-SQL LLM serving
